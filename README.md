# Aether Android Client

یک رابط کاربری (UI) مدرن، مینیمال و تولیدی (Production-Ready) برای مدیریت هسته پروکسی **Aether (نسخه 2.3.0)** مخصوص سیستم‌عامل اندروید.

## 🚀 ویژگی‌ها و قابلیت‌ها

1. **مدیریت کامل پروسه (Process Lifecycle Management):**
   - استخراج غیرهمزمان باینری هسته `aether` در حافظه برنامه و تنظیم سطح دسترسی اجرایی.
   - تنظیم متغیرهای محیطی استاندارد (`AETHER_SOCKS`, `AETHER_PROTOCOL`, `AETHER_TRANSPORT`, `AETHER_SCAN_MODE`, `AETHER_STATS`).
   - آزادسازی پورت 1819 و بستن کامل پروسه باینری هنگام قطع اتصال یا خروج از برنامه.

2. **پشتیبانی از دو حالت مسیریابی (Routing Modes):**
   - **حالت SOCKS5 Proxy:** اجرا در سطح دسترسی عادی کاربر رو پورت ۱۸۱۹.
   - **حالت System-Wide VPN (TUN Mode):** تونل کردن کامل ترافیک سیستم‌عامل از طریق سرویس نیتیو `VpnService` اندروید.

3. **داشبورد مدرن و تم تیره (Dark OLED Dashboard):**
   - دکمه مرکزی بزرگ اتصال با انیمیشن وضعیت (Idle, Connecting, Connected, Error).
   - نمایش پینگ (RTT)، مدت زمان اتصال (Uptime) و پورت محلی.
   - تنظیمات پیشرفته MASQUE (HTTP/3 و HTTP/2) و Scan Mode.

4. **ترمینال زنده لاگ‌ها (Diagnostics & Logs Console):**
   - نمایش لحظه‌ای stdout/stderr هسته Aether همراه با فیلتر سطح خطا و پاک‌سازی.

5. **سیستم به‌روزرسانی و سلامت فایل (SHA-256 Checksum):**
   - بررسی خودکار نسخه از طریق API گیت‌هاب و اعتبارسنجی هش SHA-256 قبل از نصب.

6. **بومی‌سازی دو زبانه (Localization):**
   - پشتیبانی کامل از زبان‌های فارسی (RTL) و انگلیسی (LTR).

## 🛠 ساخت و کامپایل

پروژه به صورت خودکار توسط **GitHub Actions** بیلد می‌شود. برای ساخت دستی:

```bash
./gradlew assembleDebug
```
